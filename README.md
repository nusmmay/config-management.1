# Инструмент визуализации графа зависимостей пакетов

**Практическая работа. Вариант 15.**

Инструмент для анализа и визуализации графа зависимостей пакетов Rust (Cargo). Готовые средства для получения зависимостей не используются.

## Функции

1. Принимает параметры через опции командной строки.
2. Получает данные о зависимостях Rust-пакетов через API crates.io.
3. Строит граф зависимостей и выполняет над ним операции.
4. Визуализирует граф.

## Параметры

| Параметр | Флаг | Обяз. | По умолч. | Описание |
| :--- | :--- | :--- | :--- | :--- |
| package | -p, --package | Да | — | Имя пакета |
| version | -v, --version | Да | — | Версия пакета |
| repo | -r, --repo | Да | — | URL репозитория |
| test-mode | -t | Нет | False | Тестовый режим |
| output | -o | Нет | graph.png | Имя файла графа |
| ascii-tree | -a | Нет | False | ASCII-дерево |
| filter | -f | Нет | "" | Фильтр пакетов |

## Запуск

```bash
./run.sh --package <имя> --version <версия> --repo <url>
