# Инструмент визуализации графа зависимостей пакетов

**Практическая работа. Вариант 15.**

Инструмент для анализа и визуализации графа зависимостей пакетов менеджера пакетов **Rust (Cargo)**. Готовые средства для получения зависимостей не используются.

## Общее описание

CLI-приложение на Python, которое:
1. Принимает параметры через опции командной строки.
2. Получает данные о зависимостях Rust-пакетов.
3. Строит граф зависимостей и выполняет над ним операции.
4. Визуализирует граф в различных форматах.

## Описание функций и настроек

| Параметр | Флаг | Обязательный | По умолчанию | Описание |
| :--- | :--- | :--- | :--- | :--- |
| package | `-p`, `--package` | Да | — | Имя анализируемого пакета |
| repo | `-r`, `--repo` | Да | — | URL-адрес репозитория или путь к тестовому файлу |
| test-mode | `-t`, `--test-mode` | Нет | False | Режим работы с тестовым репозиторием |
| output | `-o`, `--output` | Нет | graph.png | Имя файла с изображением графа |
| ascii-tree | `-a`, `--ascii-tree` | Нет | False | Вывод зависимостей в формате ASCII-дерева |
| filter | `-f`, `--filter` | Нет | "" | Подстрока для фильтрации пакетов |

## Команды для сборки и запуска

```bash
# Запуск приложения
./run.sh --package <имя> --repo <url> [опции]

# Или напрямую через Python
python3 src/main.py --package <имя> --repo <url> [опции]
./run.sh --package serde --repo https://crates.io --output graph.png
